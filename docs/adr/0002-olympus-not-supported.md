# Olympus 2207 excluded from campaign support

Olympus was in the original ask alongside Et Tu, Sonora, RPU and Nevada, but is dropped
entirely: fallout2-ce's own README lists it as "partially work[ing] but not fully
supported," and it has no official GitHub repo or releases — it's distributed via ModDB /
a Google Drive installer, so there's no stable asset to automate against the way the
other four have. Revisit if either changes (full CE support lands, or an official
versioned release appears).
